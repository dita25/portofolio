## **⚡ 5-MINUTE DEPLOYMENT**

### **Step 1: Open Terminal**
```powershell
cd "c:\Users\ASUS\OneDrive\Documents\PORTOFOLIO\portofolio dita2"
```

### **Step 2: Initialize Git**
```bash
git init
git add .
git commit -m "Portfolio v2.0: Supabase integration & production ready"
```

### **Step 3: Create GitHub Repository**
1. Go to [github.com/new](https://github.com/new)
2. Repository name: `portfolio`
3. Description: `My professional portfolio with Supabase database`
4. Public
5. Click "Create repository"

### **Step 4: Connect & Push**
```bash
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git branch -M main
git push -u origin main
```

### **Step 5: Enable GitHub Pages**
1. Go to your repository
2. Click **Settings** (top right)
3. Scroll to **Pages** (left sidebar)
4. Source: **Deploy from branch** → **main**
5. Click **Save**
6. Wait 1-2 minutes...
7. Your site is live! 🎉

## **🆘 Troubleshooting**

### **Site doesn't load?**
1. Check GitHub Pages is enabled (Settings → Pages)
2. Wait 2-3 minutes
3. Clear browser cache (Ctrl+Shift+Delete)
4. Try different browser

### **Assets not showing?**
1. Check relative paths use `./` prefix
2. Verify file names are correct
3. Check browser console (F12) for errors

### **Admin mode not working?**
1. Clear browser cache
2. Try in incognito mode
3. Check password in constants.js
4. Verify localStorage enabled

### **Supabase not syncing?**
1. Check internet connection
2. Verify Supabase credentials in constants.js
3. Check browser console for errors
4. Fallback to localStorage still works
